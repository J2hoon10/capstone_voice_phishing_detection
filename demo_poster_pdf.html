AIShield: 실시간 음성 보이스피싱 탐지 및 대응 가이드 시스템
통화 음성을 실시간으로 텍스트화하고, 대화 문맥을 분석해 보이스피싱 위험을 탐지한 뒤 사용자에게 즉시 대응 가이드를 제공하는 AI 기반 데모 시스템
김나현 · 장수효 · 정지훈
서울과학기술대학교 인공지능응용학과
“통화가 끝난 뒤 대응하는 것이 아니라, 통화 중에 위험을 감지하고 바로 대응할 수 있도록 돕는 보이스피싱 탐지 시스템”

1. 문제 배경 및 필요성

보이스피싱은 정상 번호 도용, 기관 사칭, 심리적 압박, 딥페이크 음성 등으로 빠르게 고도화되고 있다. 기존 블랙리스트 기반 탐지는 대화의 의미와 문맥을 해석하지 못해 한계가 있다.

  • 통화 중 심리적 압박으로 순간 판단 실패 발생
  • 사후 분석보다 실시간 개입이 중요
  • 고령층·디지털 취약계층 보호 필요
  • 온디바이스 지향 구조를 통한 프라이버시 보호

2. 시스템 파이프라인

음성 입력 → STT(Whisper) → 텍스트 분류기 → 피싱 유형 예측 → 대응 가이드 제공

AI 기술: Whisper, KoELECTRA, Streaming Belief v5, Mamba SSM

서비스 기술: FastAPI, WebSocket, React + Vite, Docker

3. 분류 대상

상품 가입 및 해지 이체 출금 대출서비스 잔고 및 거래내역 수사기관 사칭형 대출 사기형
고위험 범주인 수사기관 사칭형과 대출 사기형은 실제 보이스피싱과 직접적으로 연관된 클래스로 설정하였다.

4. 모델 설계

긴 통화 내용을 한 번에 처리하지 않고 세그먼트 단위로 나누어 순차적으로 이해하는 구조를 적용하였다.

  • KoELECTRA: 각 세그먼트 의미 인코딩
  • Attention-weighted Pooling: 핵심 정보 압축
  • Mamba SSM: 세그먼트 간 문맥 누적
  • Classification Head: 최종 유형 예측
이 구조를 통해 긴 통화에서도 뒤늦게 등장하는 위험 문장을 흐름 속에서 반영할 수 있다.

5. 실험 설정

  • 학습 데이터: train.csv
  • 검증 데이터: val.csv
  • 테스트 데이터: test.csv
  • 배치 크기: 8
  • 학습 epoch: 8
  • 모델 선택 기준: Validation Macro F1
최적 모델은 Epoch 6에서 기록되었으며, 해당 체크포인트를 최종 평가에 사용하였다.

7. 결론 및 향후 계획

  • 통화 중 위험 발화를 조기에 감지하여 피해 예방 가능
  • 고령층·디지털 취약계층을 위한 실시간 보조 도구로 활용 가능
  • 금융기관·통신사 예방 서비스로 확장 가능
향후에는 데이터 증강, 클래스 불균형 완화, 오분류 분석, 실시간 latency 최적화, 경량화 및 온디바이스 적용 검증을 진행할 계획이다.
