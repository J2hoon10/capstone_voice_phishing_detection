실시간 음성 피싱 탐지 및 대응 가이드 시스템
통화 음성을 실시간으로 분석하여 보이스피싱 위험을 분류하고, 사용자에게 즉시 대응 방법을 제공하는 AI 기반 데모 시스템
김나현, 장수효, 정지훈
서울과학기술대학교 인공지능응용학과
"통화가 끝난 뒤 대응하는 것이 아니라, 통화 중에 위험을 감지하고 바로 대응할 수 있도록 돕는 보이스피싱 탐지 시스템"
1. 문제 정의 및 목표

보이스피싱은 여전히 대표적인 금융 범죄 중 하나이며, 피해자는 통화 중 심리적으로 압박을 받는 상황에서 합리적인 판단을 내리기 어렵습니다. 기존의 사후 신고 방식에서 벗어나, 실제 통화 중 위험을 조기에 감지하고 즉시 경고하는 시스템의 필요성이 큽니다.

  • 통화 음성을 기반으로 피싱 위험을 자동 분류
  • 실시간 또는 준실시간으로 결과를 사용자에게 전달
  • 상황별 대응 가이드를 함께 제공
2. 시스템 개요

본 시스템은 다음과 같은 4단계 파이프라인으로 동작합니다.

음성 입력 ➔ STT (Whisper) ➔ 텍스트 분류기 ➔ 피싱 예측 ➔ 대응 가이드
  • 사용 기술 (AI/모델링): Whisper 계열 STT, KoELECTRA, Streaming Belief v5, Mamba SSM
  • 사용 기술 (서비스): FastAPI, WebSocket, React + Vite, Docker
3. 모델 설계 아이디어

긴 통화 내용을 한 번에 처리하지 않고, 일정 길이의 세그먼트로 나누어 순차적으로 해석하도록 설계하였습니다.

  • KoELECTRA: 각 텍스트 세그먼트의 의미 인코딩
  • Attention-weighted pooling: 세그먼트 대표 벡터 생성
  • Mamba SSM: 세그먼트들의 흐름을 따라가며 문맥 누적

긴 통화에서 중요한 문맥이 뒤쪽에 등장하더라도 순차적으로 의미를 반영할 수 있습니다.

4. 분류 대상 및 데이터

총 5개 클래스로 유형을 분류하며, 배치 크기 8, 총 8 epoch으로 학습을 진행했습니다.

상품 가입 및 해지 이체 출금 대출서비스 잔고 및 거래내역 수사기관 사칭형 (고위험) 대출 사기형 (고위험)

본 연구를 통해 고위험 범주인 수사기관 사칭형 등에서 유의미한 위험 시나리오 식별 가능성을 확인하였습니다.
