배치 영역
“통화가 끝난 뒤 대응하는 것이 아니라, 통화 중에 위험을 감지하고 바로 대응할 수 있도록 돕는 보이스피싱 탐지 시스템”

1. 문제 배경 및 필요성

최근 보이스피싱은 정상 번호 도용, 기관 사칭, 심리적 압박, 딥페이크 음성 등으로 빠르게 고도화되고 있다. 기존 블랙리스트나 URL 탐지 방식은 이러한 공격의 핵심인 대화의 의미와 문맥을 이해하지 못한다.

또한 피해는 통화가 끝난 뒤가 아니라 통화 도중 발생하는 경우가 많기 때문에, 사후 분석보다 실시간 개입형 탐지 시스템이 중요하다.

  • 기존 패턴 기반 차단의 한계
  • 통화 중 심리적 압박에 따른 순간 판단 실패
  • 고령층·디지털 취약계층 보호 필요
  • 개인정보 보호를 고려한 온디바이스 지향성

3. 분류 대상

총 5개 클래스를 대상으로 유형 분류를 수행하였다.

상품 가입 및 해지 이체 출금 대출서비스 잔고 및 거래내역 수사기관 사칭형 대출 사기형
고위험 범주인 수사기관 사칭형과 대출 사기형은 실제 보이스피싱 시나리오와 직접적으로 연관되며, 나머지 클래스는 정상 금융 상담과의 구분을 위한 비교 범주로 활용하였다.

5. 실험 설정

  • 학습 데이터: train.csv
  • 검증 데이터: val.csv
  • 테스트 데이터: test.csv
  • 배치 크기: 8
  • 학습 epoch: 8
  • 모델 선택 기준: Validation Macro F1
최적 성능은 Epoch 6에서 기록되었고, 해당 체크포인트를 기준으로 최종 테스트 평가를 수행하였다.

6. 핵심 결과 해석

  • 수사기관 사칭형에서 가장 높은 탐지 성능을 보여 대표적 고위험 시나리오 식별 가능성을 확인
  • 대출 사기형 역시 비교적 안정적인 탐지 성능 확보
  • 이체 출금 대출서비스는 정상 금융 상담과 표현이 겹쳐 가장 어려운 클래스
  • Validation 대비 Test 성능이 하락해 데이터 다양성과 일반화 성능 개선이 필요
