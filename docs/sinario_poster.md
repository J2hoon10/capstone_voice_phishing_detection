# AIShield 포스터용 정리본

## Abstract

보이스피싱은 정상 번호 도용, 기관 사칭, 심리적 압박, 딥페이크 음성 등으로 빠르게 고도화되고 있으며, 기존의 블랙리스트 기반 차단이나 URL 탐지 방식만으로는 대응에 한계가 있다. 특히 피해는 통화가 끝난 뒤가 아니라 통화 도중 발생하는 경우가 많아, 사후 분석보다 실시간 개입형 탐지 시스템의 필요성이 크다.

본 프로젝트는 통화 음성을 STT로 텍스트화한 뒤, 대화의 문맥을 분석하여 보이스피싱 위험과 유형을 분류하고, 사용자에게 즉시 대응 가이드를 제공하는 AI 기반 시스템을 제안한다. 이를 위해 KLUE-RoBERTa-base 인코더와 Mamba SSM 기반 순차 모델링 구조를 결합한 계층적 스트리밍 분류기를 사용하였다.

실험 결과 validation macro F1은 0.9913, test macro F1은 0.9937을 기록하였으며, 특히 수사기관 사칭형과 대출 사기형 등 고위험 범주에서 높은 탐지 성능을 확인하였다. 본 연구는 보이스피싱을 사후 판별하는 데 그치지 않고, 통화 중 위험을 감지하고 대응을 유도하는 보호형 AI 시스템의 가능성을 보여준다.

## Data

본 실험은 음성 전사문 기반 텍스트 분류 문제로 구성되었으며, 학습 데이터는 `train`, 검증 데이터는 `val`, 테스트 데이터는 `test`를 사용하였다. 분류 대상은 다음 4개 클래스이다.

- 상담 대화
- 일상 대화
- 대출 사기형
- 수사기관 사칭형

클래스는 계층적으로 구성된다. 상담 대화와 일상 대화는 일반(normal) 상위 클래스로, 대출 사기형과 수사기관 사칭형은 피싱(phishing) 상위 클래스로 묶인다. 이 구조를 모델의 분류 헤드 설계에 직접 반영하였다.

보이스피싱 데이터는 일반 대화 데이터 대비 양이 적고 특정 유형에 편중되어 있어 클래스 불균형 문제가 존재한다. 이를 완화하기 위해 STT 오류 반영 전처리, 데이터 증강, 세그먼트 단위 위험도 레이블링(STN labeling) 등을 적용하였다.

## Method

본 시스템은 다음과 같은 파이프라인으로 동작한다.

`음성 입력 → STT 변환(Whisper) → 텍스트 전처리 → 슬라이딩 윈도우 분할 → 문맥 기반 유형 분류 → 대응 가이드 제공`

모델은 긴 통화 문맥을 처리하기 위해 텍스트 전체를 한 번에 입력하지 않고, 슬라이딩 윈도우(window=64, stride=32, max_seq_len=128) 방식으로 세그먼트를 생성하여 순차적으로 해석하도록 설계하였다.

핵심 구조는 다음과 같다.

- `KLUE-RoBERTa-base`: 각 텍스트 세그먼트의 의미를 인코딩 (d_model=768)
- `Attention-weighted Pooling`: [CLS]/[SEP]를 제외한 실제 토큰에 대한 가중합으로 세그먼트 대표 벡터 생성
- `Mamba SSM × 2`: 세그먼트 간 흐름을 따라 문맥을 누적 (d_state=16, d_conv=4, expand=2)
- `Hierarchical Classification Head`: 일반/피싱 상위 분류 후 하위 클래스를 별도 헤드로 예측, 최종 4-class 확률 조합

이 구조는 통화 후반부에 등장하는 위험 발화도 흐름 속에서 반영할 수 있다는 장점이 있다. 인코더는 초기 3 에폭 동안 완전히 고정(freeze)하여 Mamba와 헤드를 먼저 수렴시킨 뒤, 이후 상위 레이어(layer 10–11)만 단계적으로 unfreeze하는 Freeze-Init 전략을 사용하였다.

실험 설정은 다음과 같다.

- 배치 크기: 4
- 학습 epoch: 8
- 옵티마이저: AdamW (encoder LR: 1e-5, Mamba+Head LR: 5e-4, cosine decay)
- 최적 모델 선택 기준: validation macro F1
- 최적 checkpoint: epoch 6

## Result

### Validation Best (epoch 6)

- Validation accuracy: 0.9913
- Validation macro F1: 0.9913
- Validation weighted F1: 0.9913

| 클래스 | Val F1 |
|--------|--------|
| 상담 대화 | 0.9950 |
| 일상 대화 | 0.9975 |
| 대출 사기형 | 0.9826 |
| 수사기관 사칭형 | 0.9899 |

### Test Performance

- Test accuracy: 0.9938
- Test macro F1: 0.9937
- Test weighted F1: 0.9937

### Class-wise Test F1

| 클래스 | F1 | Precision | Recall |
|--------|-----|-----------|--------|
| 상담 대화 | 1.0000 | 1.0000 | 1.0000 |
| 일상 대화 | 1.0000 | 1.0000 | 1.0000 |
| 대출 사기형 | 0.9876 | 0.9803 | 0.9950 |
| 수사기관 사칭형 | 0.9874 | 0.9949 | 0.9800 |

결과적으로 상담 대화와 일상 대화는 완벽한 분류 성능을 보였고, 대출 사기형과 수사기관 사칭형 등 고위험 범주에서도 0.987 이상의 F1을 기록하였다.

### OOD 평가 (일반 대화 전용)

피싱 샘플 없이 일반 대화(상담+일상) 1,000건만으로 평가한 결과, accuracy 0.98을 기록하였다. 상담 대화 중 19건이 대출 사기형으로 오분류되었으나 일상 대화는 거의 완벽하게 분류되었다. 이는 모델이 피싱 없는 실환경에서도 과탐 없이 안정적으로 동작함을 보여준다.

## Conclusion

본 프로젝트는 보이스피싱 대응의 핵심을 기존의 번호·패턴 기반 차단에서 대화 문맥 기반의 실시간 위험 탐지로 전환하고자 하였다. 이를 위해 Whisper STT와 KLUE-RoBERTa-base + Mamba 기반 스트리밍 분류기를 결합하였고, test macro F1 0.9937이라는 높은 분류 성능을 달성하였다.

특히 본 연구의 의의는 단순 분류 정확도에만 있지 않다. 보이스피싱을 통화가 끝난 뒤 판별하는 것이 아니라, 통화 도중 위험을 감지하고 사용자가 즉시 대응할 수 있도록 돕는 보호형 AI 시스템의 가능성을 제시했다는 점에 있다. 또한 OOD 평가를 통해 피싱이 없는 일반 환경에서도 과탐 없이 안정적으로 동작함을 확인하였다.

향후에는 다음 방향으로 발전시킬 수 있다.

- 오분류 분석 기반 모델 개선 (특히 상담 대화 → 대출 사기형 오분류 케이스)
- 실시간 스트리밍 환경 latency 최적화
- 조기 탐지 성능 강화
- 경량화 및 온디바이스 배포 검증

궁극적으로 본 시스템은 디지털 취약계층 보호, 금융기관 및 통신사의 예방 서비스, 개인정보 보호를 고려한 온디바이스 보안 AI로 확장될 가능성을 가진다.
