## 2. 주요 실험 변인별 심층 분석 (Ablation Analysis)

### 2.1 인코더 미세조정 전략: 완전 미세조정이 최고 성능

세 가지 인코더 전략의 비교 결과:

| 전략 | 설명 | Accuracy | First Correct Step | Oscillation |
| :--- | :--- | :---: | :---: | :---: |
| `v5_unfreeze_all` | 전 계층 완전 미세조정 | **90.75%** | **0.298** | **0.035** |
| `v5_lora_r8` | 전 계층 LoRA (rank=8) | 89.79% | 0.309 | 0.071 |
| `v5_default` | 하위 10 레이어 동결 | 89.06% | 0.335 | 0.074 |

**v5_unfreeze_all 주요 이점**

KoELECTRA 임베딩 포함 전 계층의 가중치를 완전히 학습한 결과:

- 정확도 기준 `v5_lora_r8` 대비 **+0.96%p**, `v5_default` 대비 **+1.69%p** 향상
- 정답 최초 수렴 시점(`first_correct_step`)이 **0.298**로 전 모델 중 가장 빠름 — 대화의 약 29.8%만 청취한 뒤 올바른 분류 달성
- 번복률(`oscillation_count`)이 **0.035**로 타 모델 대비 절반 이하 수준 — 극도로 안정적인 Belief 유지
- 취약 클래스인 사회이슈 F1이 76.7%(Baseline) → 77.7%(LoRA) → **80.6%(완전 미세조정)**으로 단계적으로 개선

**훈련 안정성 주의사항**

완전 미세조정은 Epoch 2에서 훈련 손실이 6.99로 급등하는 순간적 불안정이 관찰되었습니다 (다른 모델 대비 이례적 수준). 전 계층 파라미터가 동시에 갱신될 때 발생하는 학습률 간섭으로 추정됩니다. 이후 Epoch 5(val_acc=89.92%)까지 빠르게 수렴하여 최종 최고 성능에 도달했습니다.  
**Phase 2 적용 시 인코더 Learning Rate를 1e-5 이하로 낮추거나 Warmup Ratio를 0.1 이상으로 높여 안정성을 확보하는 것을 권장합니다.**

**수렴률(Convergence Rate) 트레이드오프**

`v5_unfreeze_all`의 수렴률은 0.527로 타 모델(0.583~0.664) 대비 낮습니다.  
이는 조기 종료율(0.945)이 함께 낮아진 것과 연관되며,  
모델이 확신 임계값에 도달하는 데 다소 신중하게 접근하지만, 일단 결정하면 번복하지 않는 특성으로 해석됩니다.  
정확도와 안정성 모두 향상된 점을 감안하면 허용 가능한 트레이드오프입니다.

---

### 2.2 Mamba 상태 차원 (d_state, N) 최적화: 과적합 방지

**결과**

Mamba의 은닉 상태 크기를 키운 `v5_dstate64`(88.82%)와 `v5_dstate32`(86.99%) 모두 Baseline(89.06%)보다 성능이 하락했습니다.

**결론**

언어적 의미 압축은 KoELECTRA가 전담하고, Mamba는 '흐름(Belief)'만 추적하는 설계 원칙에 따라  
Mamba의 N 차원을 무리하게 키울 필요가 없습니다.  
오히려 차원을 키우면 2-Layer 구조에서 과적합(Overfitting)과 최적화 불안정이 발생함을 확인했습니다.  
특히 `v5_dstate32`는 번복률(0.095)이 전 모델 중 가장 높아 Belief 안정성도 크게 저하되었습니다.  
기존의 d_state=16을 유지하는 것이 최적입니다.

---

### 2.3 시간 가중치 (λ_t) 스케줄링: Phase 1에서의 한계

**결과**

초반 청크에 Loss 가중치를 부여하는 λ 값을 0.05, 0.1, 0.2로 증가시켜 보았으나,  
Baseline(균등 가중치) 대비 정확도는 미세하게 하락했습니다 (약 −0.2%p).  
세 설정 간 성능 차이도 0.06%p 이내로 통계적으로 유의미하지 않습니다.

**결론**

일반적인 주제 분류(Phase 1)에서는 대화의 후반부에 핵심 주제가 등장하는 경우도 많으므로  
초반 집중 페널티가 성능 향상에 큰 도움이 되지 않습니다.  
이 설정은 위험도를 조기 차단해야 하는 **Phase 2(보이스피싱 등 5-class)에서 본격적으로 활용**하는 것이 바람직합니다.

전체 가족 클래스 F1은 84.1%로 오히려 소폭 향상되었으므로 다른 혼동들이 더 크게 감소한 결과입니다.

## 4. 스트리밍 지표 (Streaming Metrics) 인사이트

본 아키텍처의 핵심 목표인 **'안정적인 실시간 추적'** 능력이 데이터로 증명되었습니다.

### 4.1 번복률 (Oscillation Count): v5_unfreeze_all의 압도적 안정성

| 모델 | Oscillation Count |
| :--- | :---: |
| **`v5_unfreeze_all`** | **0.035** |
| `v5_lambda02` | 0.064 |
| `v5_lora_r8` / `v5_lambda01` | 0.071 |
| `v5_dstate64` | 0.072 |
| `v5_default` | 0.074 |
| `v5_lambda005` | 0.077 |
| `v5_dstate32` | 0.095 |

`v5_unfreeze_all`의 번복률은 0.035로 타 모델(0.064~0.095) 대비 현저히 낮습니다.  
완전 미세조정된 인코더가 더 풍부하고 안정적인 의미 표현을 제공함으로써,  
Mamba의 Recurrent Belief State가 노이즈성 입력에 훨씬 견고해진 결과입니다.  
Recurrent Belief-State 설계의 안정성이 최고 수준으로 입증되었습니다.

### 4.2 조기 종료율 (Early Stop Rate): 94~98%

| 모델 | Early Stop Rate |
| :--- | :---: |
| `v5_default` | **98.4%** |
| `v5_dstate64` | 97.9% |
| `v5_lambda02` / `v5_lambda01` | 97.2% |
| `v5_lambda005` | 97.0% |
| `v5_lora_r8` | 95.6% |
| `v5_dstate32` | 95.1% |
| `v5_unfreeze_all` | 94.5% |

모든 모델에서 94.5%~98.4%의 높은 조기 종료율을 보였습니다.  
대부분의 대화가 끝까지 가기 전에 모델이 높은 확신을 가지고 예측을 확정하므로,  
실시간 탐지 시 조기 경보(Early Alert) 발동이 가능한 구조임을 의미합니다.  
`v5_unfreeze_all`이 가장 낮은 94.5%를 기록했으나, 여전히 약 95%의 대화에서 조기 종료가 발생합니다.

### 4.3 스텝별 엔트로피 (Mean Step Entropy)의 역설적 증가

`v5_lora_r8` 기준, 1~5 스텝까지는 엔트로피가 0.503 → 0.226으로 꾸준히 감소(확신 증가)하지만,  
11 스텝을 넘어가면 1.35로 갑자기 폭증하는 현상이 관찰됩니다.

이는 모델이 헷갈려진 것이 아니라,  
약 95%의 쉬운 대화들은 이미 초반에 Early Stop으로 평가에서 빠져나가고,  
**끝까지 들어도 애매한 극도로 어려운 5%의 대화들만 후반부 스텝에 남아 있기 때문에**  
발생하는 자연스러운 통계적 편향(Selection Bias)입니다.

**v5_unfreeze_all의 독특한 엔트로피 패턴**

`v5_unfreeze_all`은 초반 엔트로피가 0.55 수준으로 유지되다가(타 모델은 0.13~0.38 수준),  
스텝 8~10에서 일시적으로 상승(0.63~1.15)한 뒤 스텝 11~12에서 다시 하락(0.28~0.36)하는  
독특한 패턴을 보입니다.  
이는 완전 미세조정 모델이 초반에 확률 분포를 신중하게 유지하다가,  
충분한 맥락이 쌓이면 빠르게 확신을 형성하는 전략적 특성임을 시사합니다.  
낮은 번복률(0.035)과 빠른 최초 정답 시점(0.298)이 이를 뒷받침합니다.

## 5. 최종 결론 및 Phase 2 제언

현재 설계된 **[Sliding Window + KoELECTRA + 2-Layer Mamba]** 아키텍처는  
스트리밍 텍스트 분류에서 약 90.75%에 달하는 우수한 정확도와  
극히 낮은 번복률·레이턴시 특성을 만족하고 있습니다.

### Phase 1 결론

| 항목 | 결과 |
| :--- | :--- |
| 최고 성능 모델 | `v5_unfreeze_all` (Accuracy 90.75%, Macro F1 0.9074) |
| 최적 인코더 전략 | 전 계층 완전 미세조정 (LoRA 대비 +0.96%p, Baseline 대비 +1.69%p) |
| 차선 인코더 전략 | LoRA rank=8 — 메모리 제약 환경에서의 실용적 대안 |
| 최적 Mamba 설정 | d_state=16 유지 (확장 시 정확도 저하 + 번복률 상승) |
| 시간 가중치 | Phase 1에서는 균등(λ=0.0)이 최적 |
| Belief 안정성 | Oscillation ≈ 0.035 (unfreeze_all), Early Stop Rate ≈ 94.5~98.4% (검증 완료) |
| 훈련 유의사항 | 완전 미세조정 시 Epoch 2 손실 급등(6.99) 관찰 → 인코더 LR 조정 필요 |

### Phase 2 진입을 위한 액션 아이템

**1. 완전 미세조정(Unfreeze All) 전면 도입**

`v5_unfreeze_all`이 정확도·안정성 모두에서 최고 성능을 달성했으므로,  
KoELECTRA 전 계층 완전 미세조정을 기본(Default) 파이프라인으로 확정합니다.  
단, 학습 안정성 확보를 위해 **인코더 Learning Rate를 1e-5 이하로 낮추고 Warmup Ratio를 0.1 이상으로 증가**하는 것을 권장합니다.

**2. LoRA는 메모리 제약 환경의 대안으로 유지**

완전 미세조정이 어려운 환경(GPU 메모리 제한 등)에서는 LoRA(rank=8)가  
완전 미세조정 대비 −0.96%p의 최소한의 성능 손실만으로 실용적 대안이 됩니다.

**3. Mamba State 차원 유지**

Mamba의 은닉 상태 크기를 무리하게 확장하지 않습니다.  
현재의 작고 가벼운 State(d_state=16)가 연속성 유지에 유리합니다.

**4. 손실 함수 전환 (Hierarchical Prototype Loss 활성화)**

일반 분류 검증이 끝났으므로, 계획서에 명시된 `Hierarchical Prototype Loss`를 활성화하여  
5단계 위험도(0~4)에 따른 임베딩 거리 페널티 학습을 시작합니다.

**5. 시간 가중치 (λ) 재평가**

Phase 1에서는 무의미했지만, Phase 2의 보이스피싱 조기 탐지에서는  
α=0.1 ~ 0.2 스케줄링이 범죄 피해 예방(Early Detection) 측면에서 핵심적인 역할을 할 것입니다.  
Phase 2 데이터로 다시 Ablation을 진행합니다.
