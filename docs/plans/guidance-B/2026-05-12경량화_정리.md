# Classifier 경량화 실험 정리

## 1. 목적

보이스피싱 탐지 모델은 실시간 통화 스트림에서 빠르게 동작해야 하므로, 단순히 높은 분류 성능만으로는 충분하지 않다. 실제 서비스 환경에서는 모델 크기, 추론 지연 시간, GPU/CPU 메모리 사용량이 함께 중요하다.

본 경량화 실험의 목적은 다음과 같다.

- 온디바이스 또는 저사양 서버 환경에서도 실행 가능한 분류 모델 확보
- Teacher 모델의 성능을 최대한 유지하면서 Student 모델의 크기와 연산량 감소
- 지식 증류(Knowledge Distillation), 파라미터 축소, 양자화(PTQ)를 비교하여 실용적인 경량화 방향 결정

## 2. Knowledge Distillation 설계

### 2.1 기본 아이디어

Knowledge Distillation은 큰 Teacher 모델이 학습한 판단 방식을 작은 Student 모델에 전달하는 방식이다. Student는 정답 라벨만 따라가는 것이 아니라, Teacher의 출력 확률 분포와 중간 표현(hidden states)을 함께 모방한다.

이 방식은 보이스피싱 탐지처럼 데이터가 제한적이고 클래스 간 경계가 애매한 문제에서 유용하다. Teacher의 soft target은 단순한 정답보다 더 많은 정보를 담는다. 예를 들어 어떤 샘플이 명확한 피싱인지, 정상 업무와 피싱 사이에서 애매한지에 대한 상대적 확률을 Student가 학습할 수 있다.

### 2.2 레포 내 구현 구조

현재 레포의 KD 관련 구조는 `models/classifier/architecture.py`에 구현되어 있다.

- Teacher: `BASE_MODEL_NAME` 기반의 full-size sequence classification 모델
- Student: `ModernBertForDistillation` 기반의 축소 모델
- Wrapper: `DistillationWrapper`
- 배포 기본 가중치 경로: `models/classifier/weights/student_best.pt`

Student 설정은 `models/classifier/config.py` 기준으로 다음과 같다.

| 항목 | Teacher 방향 | Student 설정 |
| --- | ---: | ---: |
| hidden size | 768 수준 | 384 |
| layer 수 | full-size | 11 |
| attention heads | full-size | 6 |
| intermediate size | full-size | 576 |
| max length | 1024 | 1024 |

Student는 depth와 width를 줄여 모델 용량을 낮추고, Teacher의 표현을 모방하도록 학습하는 구조다.

## 3. Distillation Loss 구성

KD 실험에서 고려하는 손실은 크게 세 가지다.

### 3.1 Hard Label Loss

일반적인 supervised classification loss다. Student가 실제 정답 라벨을 맞히도록 학습한다.

```text
L_hard = CrossEntropy(student_logits, labels)
```

### 3.2 Soft Target Loss

Teacher와 Student의 출력 확률 분포를 맞추는 손실이다. Temperature를 적용해 확률 분포를 부드럽게 만들면, Teacher가 어떤 클래스를 얼마나 헷갈려 하는지까지 Student가 배울 수 있다.

```text
L_soft = KLDiv(
    softmax(student_logits / T),
    softmax(teacher_logits / T)
)
```

### 3.3 Hidden State Loss

Teacher와 Student의 중간 layer 표현을 맞추는 손실이다. 현재 구현에서는 Teacher와 Student의 hidden size가 다를 수 있으므로 projection layer를 사용해 차원을 맞출 수 있다.

```text
student_hidden -> projection -> teacher_hidden dimension
L_hidden = MSE(projected_student_hidden, teacher_hidden)
```

Hidden state loss는 Student가 최종 정답뿐 아니라 Teacher의 내부 표현 구조까지 따라가도록 만든다. TinyBERT 계열 distillation과 유사한 방향이다.

## 4. 실험 가설

### 가설 1: Student 단독 학습보다 KD가 성능 유지에 유리하다

Student 모델은 Teacher보다 파라미터 수가 작기 때문에 단독 학습 시 표현력이 부족할 수 있다. KD를 적용하면 Teacher가 학습한 decision boundary와 클래스 간 유사도를 함께 전달받아 성능 하락을 줄일 수 있다.

### 가설 2: Soft Target만으로는 부족하고 Hidden State Loss가 필요하다

보이스피싱 대화는 긴 문맥과 발화 흐름이 중요하다. 최종 logits만 모방하면 Teacher의 내부 문맥 표현을 충분히 전달하기 어렵다. 따라서 hidden state alignment가 Student의 문맥 이해력을 보완할 가능성이 있다.

### 가설 3: KD 이후 양자화를 적용하면 추가 경량화가 가능하다

KD는 구조적 경량화이고, 양자화는 저장/연산 정밀도를 줄이는 경량화다. 두 방식은 서로 보완적이므로, KD로 작은 Student를 만든 뒤 8-bit 또는 더 낮은 bit-width 양자화를 적용하는 방향이 실용적이다.

## 5. 기존 양자화 실험 요약

레포에는 별도 경량화 실험으로 `models/classifier/experiments/sdq_ptq_bert/`가 존재한다. 이 실험은 fine-tuned BERT 계열 모델에 대해 PTQ(Post-Training Quantization)를 적용한 것이다.

주요 비교 결과는 다음과 같다.

| 실험 | Accuracy | Macro F1 | Size | Compression | Latency |
| --- | ---: | ---: | ---: | ---: | ---: |
| FP32 baseline | 0.9075 | 0.9075 | 421.98 MB | 1.00x | 0.445 ms/sample |
| RTN 2-bit | 0.6455 | 0.6418 | 118.23 MB | 3.57x | 0.422 ms/sample |
| SDQ 2-bit OSR8 | 0.6013 | 0.5329 | 118.23 MB | 3.57x | 0.422 ms/sample |
| SDQ adaptive 1.0-bit | 0.5251 | 0.3946 | 108.10 MB | 3.90x | 0.427 ms/sample |
| SDQ adaptive 1.5-bit | 0.5269 | 0.3986 | 113.17 MB | 3.73x | 0.428 ms/sample |
| SDQ adaptive 2.0-bit | 0.5269 | 0.3986 | 118.23 MB | 3.57x | 0.427 ms/sample |

해석:

- 2-bit 이하 PTQ는 모델 크기를 약 3.5~3.9배 줄였지만, 성능 손실이 매우 컸다.
- 단순 RTN 2-bit가 SDQ 2-bit보다 이 실험에서는 더 높은 성능을 보였다.
- latency 개선 폭은 크지 않았다. 현재 측정 환경에서는 모델 크기 감소가 곧바로 큰 추론 속도 개선으로 이어지지는 않았다.
- 따라서 극저비트 PTQ 단독 적용은 최종 탐지 모델에는 위험하며, KD 또는 QAT(Quantization-Aware Training)와 결합하는 방향이 더 적절하다.

## 6. Streaming Belief 모델과의 연결

현재 주력 모델은 `streaming_belief_v5_phishing5`이며, 구조는 KoELECTRA + Attention-weighted Pooling + 2-layer Mamba SSM + Classification Head다.

이 모델에 대한 경량화 방향은 다음과 같이 나눌 수 있다.

### 6.1 Encoder 경량화

KoELECTRA encoder가 전체 파라미터와 연산의 대부분을 차지한다. 따라서 가장 큰 경량화 효과는 encoder에서 나온다.

가능한 방법:

- KoELECTRA-base를 작은 Student encoder로 distillation
- 하위 layer freeze 유지
- LoRA 기반 parameter-efficient fine-tuning
- encoder output을 캐싱할 수 있는 배치 평가 구조 개선

### 6.2 Mamba/Head 경량화

Mamba 부분은 encoder에 비해 상대적으로 작지만, streaming inference에서는 매 청크마다 상태를 갱신하므로 latency에 영향을 준다.

가능한 방법:

- Mamba layer 수 2 -> 1 ablation
- d_state 16/32/64 비교
- head hidden dim 축소
- auxiliary head 제거 여부 비교

### 6.3 KD 적용 방식

Streaming Belief 모델에서 KD를 적용한다면 Teacher와 Student를 다음처럼 둘 수 있다.

| 역할 | 후보 |
| --- | --- |
| Teacher | 현재 최고 성능의 KoELECTRA + Mamba 모델 |
| Student | 더 작은 KoELECTRA/ModernBERT encoder + 1-layer Mamba |
| Distillation target | 최종 5-class logits, 청크별 logits, hidden state, segment risk logits |

특히 streaming 모델은 최종 출력뿐 아니라 `all_logits`를 통해 청크별 예측 흐름을 제공한다. 따라서 Student가 마지막 예측만 따라가는 것이 아니라, 통화가 진행되는 중간 단계의 belief 변화까지 모방하도록 학습할 수 있다.

## 7. 권장 실험 순서

### Step 1. Baseline 측정

현재 최고 성능 모델의 기준치를 고정한다.

- Accuracy
- Macro F1
- Class-wise F1
- 모델 크기
- 평균 latency
- streaming 환경에서 segment당 latency

### Step 2. 구조 축소 Student 학습

Student 구조 후보:

- Encoder layer 수 축소
- hidden size 축소
- Mamba 2-layer -> 1-layer
- head hidden dim 축소

이 단계에서는 KD 없이 hard label만으로 먼저 학습하여 Student 단독 성능을 확인한다.

### Step 3. KD 적용

Loss 조합을 순차적으로 비교한다.

| 실험 | Hard Label | Soft Target | Hidden State | Chunk Logit |
| --- | :---: | :---: | :---: | :---: |
| Student-only | O | X | X | X |
| KD-Logit | O | O | X | X |
| KD-Hidden | O | X | O | X |
| KD-Full | O | O | O | O |

### Step 4. 양자화 적용

KD로 성능을 회복한 Student에 대해 양자화를 적용한다.

- 우선 8-bit 또는 dynamic quantization부터 검증
- 4-bit 이하 또는 2-bit PTQ는 성능 손실이 컸으므로 후순위
- 필요 시 QAT로 전환

## 8. 보고서용 요약 문장

본 프로젝트의 경량화 실험은 실시간 보이스피싱 탐지 모델을 온디바이스 또는 저사양 서버 환경에서도 활용하기 위한 목적에서 수행되었다. Knowledge Distillation은 큰 Teacher 모델의 출력 분포와 중간 표현을 작은 Student 모델에 전달하여, 모델 크기와 연산량을 줄이면서도 탐지 성능 손실을 최소화하는 방법이다. 레포 내 구현은 Teacher-Student 구조, hidden state alignment, projection layer를 포함하며, 최종적으로 `student_best.pt` 형태의 경량 모델 배포를 목표로 한다. 별도의 PTQ 실험에서는 2-bit 이하 양자화가 약 3.5배 이상의 모델 크기 감소를 달성했으나 성능 손실이 크게 나타났기 때문에, 최종 적용에는 KD 기반 Student 모델을 먼저 확보한 뒤 8-bit 수준의 보수적 양자화 또는 QAT를 결합하는 방향이 적절하다.

## 9. 포스터용 요약

**Model Lightweighting**  
Teacher 모델의 판단 분포와 중간 표현을 작은 Student 모델에 전달하는 Knowledge Distillation을 통해 실시간 탐지 모델의 크기와 연산량을 줄인다. 추가로 양자화 실험을 통해 저장 크기 감소 가능성을 검증했으며, 극저비트 PTQ는 성능 손실이 커 KD 기반 Student 모델과 보수적 양자화를 결합하는 방향을 채택한다.
