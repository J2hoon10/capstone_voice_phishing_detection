## 2. 테스트 성능 비교 (전체 지표)

| 모델 | Accuracy | Macro F1 | Weighted F1 | Micro F1 |
|---|---|---|---|---|
| **RoBERTa + AvgPool** | **0.9183** | **0.9187** | **0.9183** | **0.9183** |
| BERT + AvgPool | 0.8949 | 0.9023 | 0.8951 | 0.8949 |
| KoBERT + AvgPool | 0.8872 | 0.8955 | 0.8872 | 0.8872 |
| RoBERTa + MaxPool | 0.8872 | 0.8938 | 0.8865 | 0.8872 |

> **성능 순위 (Test Macro F1 기준)**: RoBERTa_Avg > BERT_Avg > KoBERT_Avg > RoBERTa_Max > KoELECTRA_Baseline > KoELECTRA_Max

### 핵심 관찰

- **RoBERTa가 모든 테스트 지표에서 최고 성능** — Accuracy·Macro F1 모두 1위
- **BERT는 Validation 기준 최고였으나 테스트에서 RoBERTa에 역전** — Val-Test 갭이 가장 큼 (4.4%p)
- **KoBERT는 테스트 성능 최저** — Val 기준 안정적이나 일반화가 상대적으로 떨어짐

## 3. Val vs. Test Macro F1 갭 분석 (과적합 지표)

| 모델 | 최고 Val Macro F1 (Epoch) | Test Macro F1 | Val-Test 갭 |
|---|---|---|---|
| RoBERTa + AvgPool | 0.9318 (Epoch 5) | 0.9187 | **-1.3%p** |
| BERT + AvgPool | 0.9463 (Epoch 4) | 0.9023 | **-4.4%p** |
| KoBERT + AvgPool | 0.9359 (Epoch 7) | 0.8955 | -4.0%p |
| RoBERTa + MaxPool | 0.9362 (Epoch 3) | 0.8938 | **-4.2%p** |
| KoELECTRA + MaxPool | 0.8554 (Epoch 6) | 0.8138 | -4.1%p |
| KoELECTRA (Baseline) | 0.8047 (Epoch 8) | 0.8146 | +1.0%p |

- RoBERTa_Avg의 Val-Test 갭(1.3%p)이 가장 좁아 **일반화 성능이 압도적으로 우수**
- MaxPooling 적용 시(`RoBERTa + MaxPool`) Val 성능은 높았으나(0.9362), Test F1은 0.8938로 급락하며 **과적합이 심화**되는 경향을 보임 (-4.2%p 갭)
- BERT는 Epoch 4에서 갑자기 Val F1이 튀어오른 뒤(0.9463), Epoch 5에서 0.9292로 급락하는 패턴 → Epoch 4 체크포인트가 Validation에 운 좋게 맞춰진 국소 최적점일 가능성
- KoBERT의 4.0%p 갭은 어휘 크기(8,002 vocab) 한계 및 SentencePiece 기반 토크나이저의 한국어 금융 도메인 커버리지 부족이 원인으로 추정

## 8. 결론 및 분석

### 8-1. RoBERTa (klue/roberta-base) 우위 원인 분석

1. **풍부한 사전학습 코퍼스**: KLUE RoBERTa는 뉴스·위키·웹 크롤링 등 대규모 한국어 데이터로 학습 → 금융·법률 도메인 어휘 커버리지 높음
2. **NSP 태스크 제거**: RoBERTa는 Next Sentence Prediction 없이 MLM만으로 학습 → 의미론적 문장 표현이 BERT보다 우수
3. **낮은 Val-Test 갭**: 과적합 없이 일반화가 잘 되어 실제 테스트에서 강건한 성능 유지

### 8-2. BERT (klue/bert-base) 과적합 패턴

- Epoch 4의 갑작스러운 Val F1 급등(0.9463)은 학습 노이즈에 의한 운 좋은 체크포인트 가능성 높음
- Epoch 5~8에서 Val F1이 지속적으로 낮게 유지(0.929~0.936) → 해당 구간이 더 안정적인 일반화를 나타냄
- 체크포인트 전략을 `best-val`이 아닌 `late-epoch average`로 변경하면 개선 가능성 있음

### 8-3. KoBERT 저조 원인 분석

1. **소규모 어휘(8,002 SP 토큰)**: 한국어 금융·사기 도메인 전문 용어를 표현하기에 vocab 크기가 작음 → 동일 의미를 여러 sub-word로 분해, 문맥 표현 밀도 하락
2. **초기 학습 손실 높음(1.065)**: 인코더 표현이 초기화 시 태스크 도메인과 거리가 있음
3. **느린 수렴**: Epoch 3까지 타 모델 대비 낮은 Val F1 → 동일 에폭 예산에서 최적화가 불충분

### 8-4. 공통 약점: 이체 출금 대출서비스 클래스

- 세 모델 모두 이 클래스의 F1이 가장 낮음
- 이 클래스는 이체, 출금, 대출이라는 서로 다른 의미를 하나의 레이블로 묶은 복합 클래스
- `잔고 및 거래내역`, `상품 가입 및 해지`와 표면적 어휘 중복이 많음 → 경계가 모호함
- **개선 방향**: 해당 클래스 집중 데이터 증강 또는 클래스 정의 세분화 검토 필요

### 8-5. 풀링 방식 상세 비교: AvgPool vs MaxPool

1. **전반적 우위**: RoBERTa와 KoELECTRA 모두 **Avg/Attn Pooling**이 MaxPooling보다 안정적인 성능을 보임
2. **RoBERTa에서의 차이 (-2.5%p)**:
    *   AvgPool(0.9187) >> MaxPool(0.8938)
    *   RoBERTa의 정교한 문맥 정보가 MaxPooling에 의해 단순화되면서 정보 손실이 크게 발생함
3. **KoELECTRA에서의 차이 (-0.08%p)**:
    *   AttnPool(0.8146) ≈ MaxPool(0.8138)
    *   KoELECTRA는 풀링 방식에 따른 성능 차이가 거의 없음. 이는 인코더 자체가 이미 특정 키워드 위주로 특징을 추출하고 있음을 시사함
4. **공통적 과적합 패턴**:
    *   MaxPooling은 Validation에서는 높은 점수를 얻으나 Test에서는 급락함 (Val-Test 갭 약 4.1~4.2%p)
    *   특정 강력한 토큰에 의존하는 특성상 데이터의 미세한 분포 변화(Val ↔ Test)에 취약함
5. **클래스별 영향**:
    *   **금융정보형**: AvgPool이 문맥을 다각도로 파악하여 오분류를 줄임
    *   **피싱형**: MaxPool이 "검찰", "저금리" 등 핵심 단어를 강하게 포착하여 피싱 탐지 자체에는 효과적일 수 있음 (실제로 대출사기 클래스 F1은 MaxPool이 대등하거나 소폭 높음)
