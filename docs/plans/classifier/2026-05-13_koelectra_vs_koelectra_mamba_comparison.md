## 7. 결론 및 권고사항

### 7-1. 최적 구성: KoELECTRA + Mamba L1

- Mamba 레이어 1개 추가로 **Accuracy +5.1%p, Macro F1 +2.8%p** 달성
- 금융 정보형 클래스 전반 개선: 상품가입(+8.1%p), 이체출금(+6.5%p), 잔고내역(+7.2%p)
- **단, 피싱형 핵심 클래스는 소폭 하락**: 수사기관(-2.4%p), 대출사기(-5.4%p) — 향후 보완 필요
- 학습 안정성 완전 확보, 학습 속도 증가 없음

### 7-2. L2는 Baseline 대비 전반 하락

- L2는 금융 정보형 클래스에서 Baseline보다 현저히 낮음 (이체출금: 0.691 → 0.487)
- 수사기관 클래스(0.914)는 L1(0.904)보다 소폭 우위이나 전체 Accuracy는 71.2%로 가장 낮음
- L1, Baseline 모두에 비해 열세 — 추가 개선 없이는 채택 불가

### 7-3. L4, L6 NaN 문제 — 필수 해결 과제

NaN 폭발 해결을 위한 권고 조치:

1. **그래디언트 클리핑 강화**: `max_norm` 값을 1.0 → 0.5 수준으로 낮추기
2. **Mamba 레이어 학습률 분리**: KoELECTRA 대비 Mamba 레이어에 낮은 lr 적용 (예: 0.1× ~ 0.3×)
3. **레이어 정규화 추가**: Mamba 입·출력 전후 LayerNorm 추가
4. **웜업 연장**: 현재 Cosine Annealing warmup 구간에서 NaN 발생 → warmup step 증가
5. **초기화 방법 개선**: Mamba selective state matrix 초기화 스케일 점검 (예: `dt_init` 값)

> 참고: 현 레포지토리에 이미 `koelectra_mamba_diff_lr`, `koelectra_mamba_freeze_init` 실험 브랜치가 생성되어 있어 위 해결 방향과 일치하는 접근이 준비된 상태.

### 7-4. 향후 실험 방향

| 우선순위 | 실험 | 기대 효과 |
|---|---|---|
| ★★★ | L1 구성 + diff_lr (Mamba lr × 0.1) | NaN 없이 L4+ 성능 가능성 탐색 |
| ★★★ | L1 구성 + freeze_init (KoELECTRA 초기 동결) | 파인튜닝 안정성 및 Mamba 독립 학습 효과 |
| ★★ | L2 + 그래디언트 클리핑 강화 | L2 잠재 성능 재평가 |
| ★★ | L1 + 데이터 증강 (LLM/ASR) | 이체출금 클래스 추가 강화 |
| ★ | L4 + NaN 대응 (warmup + clip) | 깊은 Mamba의 한계 재평가 |
