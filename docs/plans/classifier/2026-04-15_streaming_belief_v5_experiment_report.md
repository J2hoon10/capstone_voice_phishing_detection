# 실험 결과 분석 보고서: Streaming Belief-State Classification (Phase 1)

작성일: 2026-04-15  
대상 실험: `streaming_belief_v5` — 7가지 Ablation  
데이터셋: 20-Class 멀티턴 대화 (한국어)  
아키텍처: Sliding Window + KoELECTRA + 2-Layer Mamba SSM

---

## 1. 종합 성능 요약

본 실험은 20-Class 멀티턴 대화셋을 대상으로 모델의 범용 분류 성능 및 스트리밍 환경에서의 Belief(상태) 추적 능력을 검증하기 위해 진행되었습니다.  
총 7가지의 하이퍼파라미터 변인(Ablation) 모델을 평가한 결과, **KoELECTRA 전 계층에 LoRA를 적용한 모델(`v5_lora_r8`)이 89.79%의 최고 정확도를 기록**하며 가장 우수한 성능을 입증했습니다.

| 실험 세팅 | Accuracy | Macro F1 | First Correct Step | Convergence Rate |
| :--- | :---: | :---: | :---: | :---: |
| **`v5_lora_r8` (최고 성능)** | **89.79%** | **0.8978** | **0.309** (가장 빠름) | 0.653 |
| `v5_default` (Baseline) | 89.06% | 0.8906 | 0.335 | **0.663** |
| `v5_lambda02` (α=0.2) | 88.87% | 0.8885 | 0.346 | 0.641 |
| `v5_lambda005` (α=0.05) | 88.81% | 0.8881 | 0.335 | 0.621 |
| `v5_dstate64` (N=64) | 88.81% | 0.8882 | 0.337 | 0.648 |
| `v5_lambda01` (α=0.1) | 88.80% | 0.8881 | 0.345 | 0.653 |
| `v5_dstate32` (N=32) | 86.99% | 0.8700 | 0.372 | 0.582 |

## 2. 주요 실험 변인별 심층 분석 (Ablation Analysis)

### 2.1 인코더 미세조정 전략: LoRA의 압도적 효율성

**결과**

`v5_default`(하위 10 레이어 동결) 대비 `v5_lora_r8`(LoRA rank=8 적용) 모델이 정확도를 약 **+0.73%p** 향상시켰습니다.

**스트리밍 이점**

특히 정답을 최초로 맞추는 시점(`first_correct_step`)이 0.335에서 **0.309**로 단축되었습니다.  
이는 전체 대화의 약 30%만 듣고도 올바른 문맥을 파악해 낸다는 의미로,  
실시간 탐지 레이턴시 최적화에 LoRA가 매우 효과적임을 보여줍니다.

---

### 2.2 Mamba 상태 차원 (d_state, N) 최적화: 과적합 방지

**결과**

Mamba의 은닉 상태 크기를 키운 `dstate64`(88.81%)와 `dstate32`(86.99%) 모두 Baseline(89.06%)보다 성능이 하락했습니다.

**결론**

언어적 의미 압축은 KoELECTRA가 전담하고, Mamba는 '흐름(Belief)'만 추적하는 설계 원칙에 따라  
Mamba의 N 차원을 무리하게 키울 필요가 없습니다.  
오히려 차원을 키우면 2-Layer 구조에서 과적합(Overfitting)과 최적화 불안정이 발생함을 확인했습니다.  
기존의 d_state=16을 유지하는 것이 최적입니다.

---

### 2.3 시간 가중치 (λ_t) 스케줄링: Phase 1에서의 한계

**결과**

초반 청크에 Loss 가중치를 부여하는 λ 값을 0.05, 0.1, 0.2로 증가시켜 보았으나,  
Baseline(균등 가중치) 대비 정확도는 미세하게 하락했습니다 (약 -0.2%p).

**결론**

일반적인 주제 분류(Phase 1)에서는 대화의 후반부에 핵심 주제가 등장하는 경우도 많으므로  
초반 집중 페널티가 성능 향상에 큰 도움이 되지 않습니다.  
이 설정은 위험도를 조기 차단해야 하는 **Phase 2(보이스피싱 등 5-class)에서 본격적으로 활용**하는 것이 바람직합니다.

`v5_lora_r8` 모델 기준, 클래스별 F1 Score를 분석한 결과 확연한 성능 편차가 존재합니다.

## 4. 스트리밍 지표 (Streaming Metrics) 인사이트

본 아키텍처의 핵심 목표인 **'안정적인 실시간 추적'** 능력이 데이터로 증명되었습니다.

### 4.1 번복률 (Oscillation Count): 극히 낮음

전 모델에서 약 **0.06 ~ 0.09**를 기록했습니다.

Mamba가 대화 도중 정답을 한 번 맞추면, 이후에 노이즈성 단어가 들어와도  
이전의 Belief를 쉽게 잃어버리지 않고 유지한다는 것을 의미합니다.  
Recurrent Belief-State의 안정성이 수치로 입증된 결과입니다.

### 4.2 조기 종료율 (Early Stop Rate): 95~98%

대부분의 대화가 끝까지 가기 전에 모델이 높은 확신을 가지고 예측을 확정합니다.  
실시간 탐지 시 조기 경보(Early Alert) 발동이 가능한 구조임을 의미합니다.

### 4.3 스텝별 엔트로피 (Mean Step Entropy)의 역설적 증가

1~5 스텝까지는 엔트로피가 0.38 → 0.22로 꾸준히 감소(확신 증가)하지만,  
10 스텝을 넘어가면 1.35 등으로 갑자기 폭증하는 현상이 관찰됩니다.

이는 모델이 헷갈려진 것이 아니라,  
98%의 쉬운 대화들은 이미 초반에 Early Stop으로 평가에서 빠져나가고,  
**끝까지 들어도 애매한 극도로 어려운 2%의 대화들만 후반부 스텝에 남아 있기 때문에**  
발생하는 자연스러운 통계적 편향(Selection Bias)입니다.

## 5. 최종 결론 및 Phase 2 제언

현재 설계된 **[Sliding Window + KoELECTRA + 2-Layer Mamba]** 아키텍처는  
스트리밍 텍스트 분류에서 약 90%에 달하는 우수한 정확도와  
극히 낮은 번복률·레이턴시 특성을 만족하고 있습니다.

### Phase 1 결론

| 항목 | 결과 |
| :--- | :--- |
| 최고 성능 모델 | `v5_lora_r8` (Accuracy 89.79%, Macro F1 0.8978) |
| 최적 인코더 전략 | LoRA rank=8 (하위 레이어 동결보다 우수) |
| 최적 Mamba 설정 | d_state=16 유지 (확장 시 오히려 성능 하락) |
| 시간 가중치 | Phase 1에서는 균등(λ=0.0)이 최적 |
| Belief 안정성 | Oscillation ≈ 0.07, Early Stop Rate ≈ 96% (검증 완료) |

### Phase 2 진입을 위한 액션 아이템

**1. LoRA 전면 도입 확정**

하위 레이어 동결 대신, KoELECTRA 전 계층에 LoRA(rank=8)를 적용하는 방식을  
기본(Default) 파이프라인으로 확정합니다.

**2. Mamba State 차원 유지**

Mamba의 은닉 상태 크기를 무리하게 확장하지 않습니다.  
현재의 작고 가벼운 State(d_state=16)가 연속성 유지에 유리합니다.

**3. 손실 함수 전환 (Hierarchical Prototype Loss 활성화)**

일반 분류 검증이 끝났으므로, 계획서에 명시된 `Hierarchical Prototype Loss`를 활성화하여  
5단계 위험도(0~4)에 따른 임베딩 거리 페널티 학습을 시작합니다.

**4. 시간 가중치 (λ) 재평가**

Phase 1에서는 무의미했지만, Phase 2의 보이스피싱 조기 탐지에서는  
α=0.1 ~ 0.2 스케줄링이 범죄 피해 예방(Early Detection) 측면에서 핵심적인 역할을 할 것입니다.  
Phase 2 데이터로 다시 Ablation을 진행합니다.
